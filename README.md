# MekaMon Remote for Android

An independent Android BLE controller for the Reach Robotics MekaMon robot.

## Features

- BLE scan and Android companion-device picker fallback
- Select a robot from discovered nearby devices
- Virtual joystick for forward, reverse, and strafing
- Turn controls, body-height control, speed setting, and short movement routines
- Emergency stop, neutral motion streaming, and stop-on-app-background behavior

## Download

The v1.1 APK is in [`release/MekaRemote-v1.1.apk`](release/MekaRemote-v1.1.apk).

## Build

Requirements: JDK 17, Android SDK Platform 35, Android Build Tools 35.0.0, Gradle 8.7, and the Android Gradle Plugin declared in `build.gradle`.

```sh
gradle assembleDebug
```

The APK will be created at `app/build/outputs/apk/debug/app-debug.apk`. A debug signing key is generated by the Android build; do not commit private signing keys.

## Bluetooth notes

The controller communicates with the robot through the Nordic UART BLE service and uses the reverse-engineered MekaMon movement framing. It sends a walking-mode transform continuously while connected and returns to neutral when the joystick is released, Emergency Stop is pressed, or the app goes to the background. MekaMon firmware and Android Bluetooth behavior may vary by device. Test on a clear surface and keep the robot's physical power switch accessible.

The movement protocol is not an official Reach Robotics SDK. Community references include [MekaMon BLE Project](https://github.com/dzik32/Mekamon-BLE-Project) and [Hackaday's BLE notes](https://hackaday.io/project/159212/instructions). This app is independent and is not affiliated with Reach Robotics.

## Android permissions

The app requests Nearby Devices/Bluetooth permissions on Android 12 and newer. On Android 11 and older, it requests Location permission for BLE scanning; Android's companion-device picker may also require Location Services to be enabled.
